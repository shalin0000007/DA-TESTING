# Execution Dashboard
## Overview
The Execution Dashboard is a professional interface for monitoring and analyzing execution metrics.
## Active Insights
The following insight cards provide key metrics for execution performance:
### Insight Cards
* Total Runs: 1,420
* Success Rate: 99.8%
* Log Storage: 12.4 GB
## Design and Layout
The insight cards are designed with a Glassmorphism effect, featuring a blurred background and translucent white borders. The cards are arranged in a responsive grid, with three columns on desktop and one column on mobile.
## Interactivity
Each insight card features a smooth scaling hover effect, providing an interactive and engaging user experience.
